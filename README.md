# AutoFarmSelect
AutoFarmSelect 是一个**纯客户端**的 Fabric 模组，适用于**生存类服务器**可以自动实现经济作物补种与灌溉器补水。

## 运行环境
| 项目 | 版本 |
|---|---|
| Minecraft | 1.21.11 |
| Fabric Loader | 0.16.0 及以上 |
| Fabric API | 必需 |
| Java | 21 及以上 |
| 运行端 | 仅客户端 |

## 使用步骤
1. 把 jar 放进 `mods` 文件夹并启动游戏。
2. 站在农田上，面朝作物。
3. 按 **H**进行补种，按 **J**进行补水（进入按键绑定页面可自定义）。

模组首次启动会读取 `config/autofarmselect/autofarmselect.json`，没有则自动生成。

## 指令
| 指令 | 说明 |
|---|---|
| `/afs cone <角度>` | 收获扇形宽度，1–180，默认 `60`。 |
| `/afs plantdist <格>` | 最大点击距离，受手臂长度限制，默认 `4.0`。 |
| `/afs mode <safe\|normal\|fast\|turbo\|insane>` | 速度档位，默认 `normal`。 |
| `/afs why` | 解释当前为什么没有在收获。 |

## 速度档位
| 档位 | 间隔（tick） | 每批点击 | 每秒发包预算 | 说明 |
|---|---|---|---|---|
| `safe` | 20 | 1 | 4 | 最保守，适合首次测试或严格服务器。 |
| `normal` | 12 | 1 | 6 | 默认，多数服务器可用。 |
| `fast` | 8 | 2 | 8 | 明显更快，预算仅略升。 |
| `turbo` | 6 | 2 | 12 | 激进，仅在你确认服务器能扛时。 |
| `insane` | 3 | 3 | 28 | 最大吞吐，最容易被踢。 |

档位越高不代表点击“更聪明”，只是提高了发包频率。留在不触发限流的较低档位，通常比每几秒就暂停的高档位更顺滑。
